# vafelkatkan.uz — yangi sayt dizayni

Claude Design kanvasi uchun manba fayllar. Har bir `.dc.html` — kanvasdagi alohida artbord.

| Fayl | Nima |
|---|---|
| `Main.dc.html` | Bosh sahifa, 1440 px, 13 blok (interaktiv) |
| `Catalog.dc.html` | Katalog: filtrlar, katak/roʻyxat koʻrinishi |
| `Product.dc.html` | Mahsulot sahifasi: galereya, spetsifikatsiya, videolar |
| `Mobile.dc.html` | Mobil bosh sahifa va vertikal video lenta |
| `System.dc.html` | Dizayn tizimi: ranglar, shriftlar, tugma holatlari, forma, soya, harakat |
| `VideoSlots.dc.html` | Tezkor videolar uchun 6 ta joy va fayl talablari |
| `Plan.dc.html` | Redizayn rejasi (bosib chiqarish uchun oqim hujjati) |
| `canvas.json` | Kanvas joylashuvi, sahifalar va izohlar |
| `vafelkatkan-sayt-dizayni.html` | Yigʻilgan kanvas (chop etilgan versiya) |

Dizayn yoʻnalishi: iliq paxta — fon `#FAF5EE`, blok `#F2E9DC`, toʻq `#2A211B`,
aksent terrakota `#C25A32`, holat zaytun `#6F8F5F`, muted matn `#7A6C5E` (WCAG AA).
Shriftlar: Newsreader (sarlavha), Manrope (interfeys), IBM Plex Mono (texnik qiymatlar).

Kvadrat qavsdagi barcha qiymatlar (`[NARX]`, `[+998 …]`, `[SERTIFIKAT]`) —
mijozdan olinadigan real maʼlumot uchun oʻrin egallovchi.
